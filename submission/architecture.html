Architecture · 2 of 3

Inputs, models, storage, interfaces

Inputs · consent · provenance

  • Media up to 20–50 MB; consent flag mandatory (UI + server-enforced).
  • Provenance inputs: C2PA manifest, EXIF (make/model/date/GPS/lens), JPEG DQT.
  • SHA-256 of raw bytes computed at ingest as the evidentiary anchor.

Models · rules

  • Primary: dima806 + Ateeqq (image), wav2vec2-xlsr (voice). HF, CPU/INT8 or Inference API.
  • Calibrator: Platt (scipy) → calibration.json.
  • Supporting: numpy/scipy DSP + rPPG + lip-sync, bounded influence.

Storage · data boundaries

  • SQLite case ledger: metadata + hash + verdict + review state.
  • No media at rest — temp files unlinked after analysis.
  • Only weights + calibration persist as model artifacts.

Interfaces · outputs

  • REST: /api/verify, case, report, escalate, review; SSE for live image.
  • Outputs: JSON report envelope + printable HTML evidence report.
  • UI: unified verify page + analyst review queue.

Architecture · 3 of 3

Decision flow, safeguards, validation

Decision & escalation

  • Confident primary → verdict + risk + plain recommendation.
  • Uncertain / conflicting / no primary → Inconclusive → auto-queue for review.
  • Reviewer confirms or overrides with a note; decision stored on the case.

Security & privacy

  • Review endpoints require REVIEWER_KEY, fail closed, no same-origin bypass.
  • Transient media, hash-only retention, consent-gated ingest.
  • Tightened CORS on mutations; rate-limited public endpoints.

Adversarial risk

  • Heuristics cannot drive the verdict → poisoning them cannot flip it.
  • Provenance forgery capped to a nudge; only verified C2PA overrides.
  • Unknown / ambiguous defaults to escalation, not a confident wrong call.

Performance & validation

  • Image ~2–8s CPU; thread-pool capped; single worker (no model duplication).
  • Validation: LOO accuracy 87%, ECE 0.047 (n=23); ROC + per-attack sets next.
  • Calibration refreshed as labelled data grows; sample size disclosed.
Synthetic / public / consented data only. Truthy is decision-support, not legal proof.
